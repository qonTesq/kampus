# Tasks

Branch `change/auth-broker`, created after `standard-token-profile` is merged and archived. Every task is ≤ 2 h. Each numbered group is a checkpoint phase that ends in a working, committed state. Check per crate while working (`cargo check -p kampus-auth --features sandbox`, `cargo test -p kampus-auth --features sandbox`); run the full gate only in group 8. Estimates are engineering time with an AI agent and exclude review waits and vendor-side delays. "Integrator" marks edits to root manifests, `Cargo.lock`, `crates/kampus` seams, `docs/contracts/` or `AGENTS.md`.
